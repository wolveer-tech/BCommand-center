# Command Centre v10.29.0

## Puzzle Arcade

- Keeps 2048, Trivia and Wordle.
- Adds playable Connections, Strands, Crossword, Mini Crossword and Sudoku games with original in-app puzzle sets.
- Adds Easy, Medium and Hard modes for the word and logic puzzles.
- Adds a single **New puzzles** action that refreshes the full arcade set while preserving long-term scores and streaks.
- Removes Snake and Reaction Test from the Games screen.
- Keeps puzzle progress on the device and updates the offline app shell for the new game assets.

## Native iOS

No native iOS rebuild is required when the installed app loads the hosted Command Centre frontend. The existing iOS 1.12.1 (build 20) shell remains compatible.
