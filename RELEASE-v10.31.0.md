# Command Centre v10.31.0

## Expanded game variety

- Gives Wordle 365 unique answers at every difficulty, enough for a full year without a repeated answer.
- Gives Trivia 375 unique questions at every difficulty, mixing general knowledge with level-appropriate number rounds.
- Builds Connections from four independent group lanes, producing thousands of valid board combinations instead of cycling eight fixed boards.
- Generates Mini Crosswords and larger Crosswords from broad answer banks; automated validation proves the first 365 at every difficulty are distinct and every crossing is valid.
- Expands each Strands theme into a larger word pool and selects different valid subsets, producing 700+ combinations per difficulty.
- Uses a coprime daily rotation and a versioned migration so existing users immediately move onto the larger non-repeating schedule.
- Makes Sudoku generate different valid completed grids by permuting digits, row bands, rows, column stacks and columns.
- Migrates existing game state to the new content pack and advances the puzzle seed once, so the first upgraded set is not the same board users just played.
- Keeps 2048’s already-random tile generation and preserves long-term best scores and streaks.

## Delivery

This release includes the v10.30.0 PWA notification routing and Games selection screen. No additional native iOS change is required beyond the included iOS 1.13.0 project.
