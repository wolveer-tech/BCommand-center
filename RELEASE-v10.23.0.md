# Safari notification companion, League One and Notes focus v10.23.0

This hosted update lets an existing paired IPA device use a Safari Home Screen
installation as its Web Push receiver. It does not add another Messages or
Transfers device and does not require an APNs `.p8` key.

## Included

- One-time, 9-digit companion linking code generated by the paired IPA.
- A restricted Safari receiver credential that can only refresh, test or
  remove its Web Push link; it cannot read Messages or Transfers.
- IPA-to-Safari sync for reminders, calendar events, morning briefing, news and
  favourite-team football alerts.
- Messages and Transfers fall back to the companion Web Push route if APNs is
  unavailable or fails.
- League One, Championship, League Two and National League club tables now use
  FotMob's public league data, with no extra Cloudflare secret.
- Notes writing mode reliably hides the note heading, title, folder, pin row and
  save footer while the iPhone keyboard is open. The small formatting dock stays.

## Deploy

Deploy the repository through the existing GitHub-to-Cloudflare workflow. The
Worker creates the small companion tables safely on first use; migration
`0011_notification_companion.sql` is also included for clean/new databases.
No new Cloudflare variable and no new IPA are required. Existing VAPID Web Push
keys must remain configured.

## Link the receiver

1. In Safari on the iPhone, open the deployed website and use **Share → Add to
   Home Screen**. Open the new Home Screen icon once.
2. In the IPA, open **Settings → Notifications → Safari notification
   companion → Link Safari**, then create a code.
3. In the Safari Home Screen app, open the same settings section, enter the
   9-digit code, tap **Allow notifications and link**, and allow notifications.
4. Return to the IPA. Leave the link screen open until it reports **Linked**,
   then tap **Send companion test**.

Tapping a Web Push notification opens the Safari Home Screen app because iOS
owns that notification route; the normal IPA remains unchanged for everything
else.
