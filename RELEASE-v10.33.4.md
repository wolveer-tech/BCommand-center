# v10.33.4 — TitaniumStream, backup sports and a complete dark palette

Sports Source 1 is now TitaniumStream (https://titaniumstream.pages.dev/), replacing the unavailable Original Provider. Its football listing supplies match names, competition, kickoff and images; each match's main and alternate players are grouped into one card. Player pages are resolved only when opened.

StreamPortal (https://streamportal.pages.dev/) is the backup for the same source, using the public feed and resolver that its own page calls. It is selected automatically if the main listing fails or has no matches, or for sports the main site does not list. A manual backup/main switch remains available for player failures that a cross-origin frame cannot reliably report. Provider 2 and SportsindX retain their configurations. Unsupported categories remain empty instead of borrowing matches from another sport.

Provider requests have a 6.5 second timeout and follow at most two redirects within the same exact origin. Resolved players require HTTPS and the exact observed hosts taifood-blog.asia, trendy48.online or embed.st. Unrelated frames, misleading suffixes, credential-bearing URLs and arbitrary page paths are rejected. Match references are encoded as query values. The feed cache separates main and backup requests and invalidates the old format. Missing player links and rejected player URLs now have separate diagnostic counts.

Sports playback offers Compatible and Restricted modes, just like Movies & TV. Compatible removes the iframe sandbox; Restricted blocks popup permissions but can prevent providers from playing. Existing native iPhone popup/navigation guards apply independently. Browser Compatible mode cannot guarantee no popups.

Every section now shares charcoal backgrounds, darker panels and inputs, restrained selected tabs, and readable foreground colours. This includes Home, side navigation, the dock, dialogs, Account, Manga, Notes, and notebook paper. Existing phone width, scroll optimisations and the removed Home swipe-down shortcut remain in place.

The material icon artwork from v10.33.3 uses steel, paper and muted accents rather than bright clay forms. Atlantic is retained as its own Movies & TV source, and Flystream is added as the seventh source. Flystream title and episode addresses follow links observed on its public home page; the remaining movie sources retain their addresses. Individual video playback still depends on each provider.

Validation: npm run check and all 213 tests passed, including eight tests covering main/backup failover, category separation, expired entries, duplicate player grouping, resolver formats and URL validation. The actual Titanium football listing parsed as seven matches with two players each. The StreamPortal feed and resolver were checked against their public response formats. Dark Home, Movies and notebook paper were inspected in browser previews, including a 390 px phone viewport with no horizontal overflow. No new IPA, account reset or database migration is needed.
